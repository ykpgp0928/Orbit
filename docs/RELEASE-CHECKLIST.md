## 四、发布表述（建议）

> **Orbit v0.4.0 — Runtime Hardening & Contract Alpha**
> 面向静态站悬浮交互 Runtime 的架构发布：实验性 Widget Contract、local-first Profile、完整生命周期回归。欢迎外部 Widget 作者试用并反馈；**Contract 尚未冻结为 1.0 API**，v0.5 允许一次受控调整。

## 五、发布后观测（延续至 v0.5 决策）

- 记录：首次接入成功率 / 步骤数、公开 API 外溢（`src/` import、私有 DOM id/class）、生命周期缺陷、Profile 往返反馈
- 规则：影响 Definition / ctx / Profile schema / 版本协商的变更默认进 v0.5 提案；`0.4.x` patch 不增加新的必选 Contract 字段
